# Contributing

This repository is maintained by **DeTraced Security**.

While the rules and IOCs are shared publicly for defenders everywhere, **contributions are restricted to our internal team**.

- External pull requests will be closed without review.
- If you have feedback, corrections, or requests, please open an **Issue**.
- Internal team members should follow the style guide documented in [`docs/STYLE-GUIDE.md`](STYLE-GUIDE.md).

Thank you for using and supporting our work.
